# Diagnostics

## Available Diagnostics

| Test | Type | Notes |
| --- | --- | --- |
| [cbm-burnin-tests](https://github.com/fachat/cbm-burnin-tests/archive/refs/heads/main.zip) | RAM/ROM + 64K | Updated classic PET burn-in suite. ([README](https://github.com/fachat/cbm-burnin-tests#readme)) |
| [8032.mem.prg](https://www.zimmers.net/anonftp/pub/cbm/pet/utilities/8032.mem.prg) | 64K Only | Despite the name, this program tests the 64K expansion board only. |
| [testram9000.d80.gz](https://www.zimmers.net/anonftp/pub/cbm/pet/SuperPET/os9/testram9000.d80.gz) | SuperPET Only | Tests SuperPET RAM and Super OS/9 MMU RAM. |
| [4.0 System RAM/ROM Test V300](https://www.zimmers.net/anonftp/pub/cbm/pet/utilities/cbm_dealer_tests.d80.gz) | RAM/ROM | On the CBM dealer test disk, run `4.0 system 40c` or `40xx memory test` for 4.0 ROMs. |
| [RAM/ROM TT110 V250](https://www.zimmers.net/anonftp/pub/cbm/pet/utilities/cbm_dealer_tests.d80.gz) | RAM/ROM | On the CBM dealer test disk, run `40c 2.0` for upgrade ROMs. |
| [System Burn-In V2007TT](https://www.zimmers.net/anonftp/pub/cbm/pet/utilities/cbm_dealer_tests.d80.gz) | RAM/ROM | On the CBM dealer test disk, run `80sysburn1039` or `80xx memory test` for 80-column systems. |
| [sp9000](https://www.zimmers.net/anonftp/pub/cbm/pet/utilities/cbm_dealer_tests.d80.gz) | SuperPET Only | On the CBM dealer test disk, run `sp9000` to test SuperPET banked memory. |
